# Dhanavel Tech — Portfolio

Multi-page responsive portfolio built with HTML, CSS, vanilla JavaScript and Vite.

## Development
`npm install` then `npm run dev`.

## Build
`npm run build`.

## Contact form configuration
Set `RESEND_API_KEY` and `CONTACT_FROM_EMAIL` in Vercel project environment variables. Verify the sending domain in Resend and use a sender address on that verified domain. Messages are delivered to dhanavelperiyasamy.cse@gmail.com. Never commit API keys.
