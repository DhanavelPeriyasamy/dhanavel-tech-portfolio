# Dhanavel Tech — Portfolio

A lightweight, responsive personal portfolio built with HTML, CSS and vanilla JavaScript, bundled with Vite.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Vercel settings: Framework Preset **Vite**, Build Command **npm run build**, Output Directory **dist**. No database, API secrets, login or environment variables are required.

## Assets

The existing résumé and portrait are kept in `public/assets/`.
